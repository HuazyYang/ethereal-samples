# Spray-deposit Slang execution plan

The retained sample voxelizes `metal.obj` with scale 200 followed by translation (200,200,200), uses fixed topology with branching (3,3,3,3,5), density values 1 for surface/interior, RGBA8 gray (0.7,0.7,0.7,1), two initial smoothing passes with center weight 4 and boundary 0. No topology expansion occurs while depositing.

1. Add an SDK-free arbitrary-ray query helper using the existing NVRHI runtime and scalar volume buffers. Preserve absolute step-wavefront sampling, trilinear atlas coordinates, threshold >=0.3, step 0.25, entry epsilon 0.01, negative gradient at +/-0.5, and hit -= direction*bias with bias -0.0001. Use explicit float4 origin/direction/hit/normal buffers; sentinel hit coordinates are 1e10, with a separate status component. Validate analytic hit, bias, normal, miss, parallel ray, signed topology and iteration-limit behavior on all four APIs.
2. Generate the original 1000-ray bundle with mt19937 seed 6572 and the original rotate/sweep/wave equations and color packing. Each animation step advances time by exactly one. Preserve RNG draw order and float normalization.
3. Reuse portable subcell binning at width 4 and radius 1. Seed the existing gather with current scalar and raw RGBA8 atlas, gather density as max(existing,1-distance), and average prior color with every point color in the subcell. Publish both buffers and update aprons. Apply one center-weight-4 smoothing pass every 20 frames. Misses never create topology.
4. Rebuild the sample around the shared viewer, retaining the previous main as `legacy-main.cpp`. Preserve camera/light orbits, Inspector and keys (1/space simulate,2 topology,3 rays,4 shading,5 wand). Keep surface color, world-space ray overlays and fixed topology observable. Coordinate missing viewer shading controls explicitly.
5. Add independent CPU references for complete small-volume deposition, including color averaging beyond the density radius, repeated accumulation, misses, zero hits, fixed topology and smoothing cadence. Add real metal asset checks, bounded native windows and CUDA memory checks after the analytic suite passes.

This plan authorizes a new implementation slice; it is not an acceptance claim. Ray traversal uses a portable leaf-grid DDA instead of the old pointer-based hierarchy traversal. Both share the same absolute sampling wavefront, but exact legacy boundary images require a dedicated comparison. Iteration exhaustion is reported explicitly rather than returned as an ordinary miss.

Branch-order audit: the legacy spray `fromBranching(3,3,3,3,5)` arguments are root-first. Production spray topology is now leaf-first `{5,3,3,3,3}` with leaf32 and 32-voxel dense bounds alignment. Small analytic tests may deliberately construct leaf8; production asset tests must assert leaf32 separately.

## Validation and compatibility limits

The query, fixed-topology deposition, five-mode renderer, scene/main and fixtures are integrated in the aggregate build. All nineteen spray CTests passed, followed by seven control/native-window checks with Inspector input and native validation enabled. The final shared overlay correction is included in the full 231-test passing matrix. CUDA memory checks of the analytic/real-asset suite, controls and three-step 1024x768 application each reported zero errors; the application memory check passed again after the overlay correction. Final three-step 128x96 pixel bytes are identical across all four APIs (`build/spray-alpha-cross-api.json`). This validates the migrated sample slice, not completion of the broader public GVDB ownership migration.

The ray helper derives sampling entry from the maximum of the biased global, leaf and ancestor-box entries. A forced three-level fixture starts at t=2.23: three additions of .01 move sampling from 2.25 to 2.5. Geometric cell selection is independent of this bias. Zero-length entry cells caused by roundoff advance without sampling, and exact negative voxel faces step forward. This fixed real cross-backend holes; 257 oblique rays, a one-cell budget, large unnormalized directions, zero epsilon and real-camera status counts guard the repair. Voxel traversal starts at the hierarchy-biased position, preserving the original thin-first-cell selection.

The five render fixtures independently evaluate Off, colored voxel Phong, colored trilinear Phong, the fixed X=50 section equation, and the legacy Beer-Lambert integration followed by its second alpha blend. A twenty-step fixture compares steps 1..19 with an explicitly unsmoothed deposition path and step 20 with a CPU six-neighbor stencil. These complement the complete CPU scalar/RGBA deposition reference and production leaf32 assertion. Forced branch hints in the pure renderer were removed after isolated compilation showed they caused FXC's false uninitialized-value diagnostics; all shader targets now compile without those warnings.

A fresh 1024x768 three-step comparison with the retained reference has RGB mean absolute error 0.392708 on the 0..255 scale, maximum channel difference 93, 5.7715% of pixels differing by more than one and 0.9982% by more than eight. Gaussian sigma-4 RGB mean absolute error is 0.282041 (`build/spray-legacy-alpha-comparison.json`). Camera and geometry match closely, and source-alpha compositing restores the translucent ray fan. Line rasterization and faint legacy face-grid shading still differ; this is not exact legacy screenshot parity. The shared overlay now composites every covering line in draw order, with independent overlapping/transparent-line regression coverage.
