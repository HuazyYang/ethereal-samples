# Raw point-stream conversion slice

This isolated Stage E module prepares validated raw-buffer descriptors and provides one Slang compute entry. It does not publish topology/channels, submit commands, authenticate arbitrary external-buffer device identity, or replace the verified legacy conversion helper. Future point factories will retain the volume and use the agreed mutation/adoption tickets.

Input and output streams preserve point and component order, with one to four components. Byte/ushort values are unsigned. Float/double bits are little-endian IEEE representations. The transform is `(minimum + value * delta) * scale + translation` in binary32 arithmetic; binary64 input rounds to binary32 and binary64 output exactly widens the result. Integer output clamps/truncates and maps nonfinite values to zero. Exact identity skips arithmetic to preserve signed zero and subnormals. Floating NaNs are canonicalized to a quiet NaN; payload/sign preservation is not promised. The retained CUDA conversion only implements ushort3/float3 input and tight float3 output; other representations/strides are explicit extensions.

Every output invocation owns one complete aligned word and preserves untouched prefix, interleaved fields, stride gaps, suffix and physical padding. Inputs reconstruct unaligned components from aligned words. Allocations must include four-byte tail padding. Direct source/destination alias is rejected; imported native aliases are a caller contract until authenticated factory recording is added. Callers must snapshot an overlapping source first.

Independent GPU fixtures compare complete byte buffers using host memcpy and native C++ numeric conversion, all 16 encoding pairs, odd offsets/strides, binary64 rounding ties and subnormals, signed zero, exceptional integer outputs, sequential position/velocity/RGBA fields sharing output words, invalid ranges and output-preserving failure, and zero-length input. Tests use the existing sample runtime only as a harness. Module implementation itself depends only on NVRHI and shared POD layouts.

Private validation passed on D3D11, D3D12, Vulkan and CUDA. Native validation passed on all three graphics APIs, and CUDA Compute Sanitizer reported zero errors. Artifacts compile without diagnostics on all four targets. Logs are under `build/point-stream-private`: `{dx11,dx12,vk,cuda}-tests.log`, `{dx11,dx12,vk}-native.log`, `cuda-memcheck.log` and target compile logs. The first D3D11 run exposed signed-zero loss when an identity value passed through floating registers; identity decode/conversion/widening now stays in integer bit operations and the boundary fixtures pass. Rounded arithmetic uses the existing target-switch pattern because pinned Slang does not lower a bare `precise` local correctly to CUDA. Non-identity arithmetic otherwise follows target binary32 denormal handling; binary64 destination is an exact widening, not a double-precision affine transform.

Aggregate checks passed 4/4 in 2.67 seconds; isolated graphics-only checks passed 3/3 in 2.50 seconds with CUDA SDK discovery disabled. Logs are `build/point-stream-{configure,build,tests}.log`, `build/point-stream-graphics-{configure,build,tests}.log`, and their test JUnit files under the respective build directories. Candidate topology/channel publication remains follow-up work. The module's descriptor preparation does no GPU recording or device authentication; these passing fixtures do not claim a completed public point-operator factory.
